## 这个站是什么

我在跨境电商行业做了几年技术交付，业务横跨**海外仓、财税合规、关税数据、内容获客**。这个站记录的是我真正交付过的系统：它们解决什么问题、怎么设计的、踩过什么坑、真实完成到什么程度。

写这个站有三条硬规矩：

1. **每条结论都有可展示的证据。** 代码片段、运行日志、截图或架构图——敏感信息已脱敏，面试可提供脱敏演示。
2. **不夸大完成度。** 原型就是原型，没上线就是没上线，只有设计文档就写"设计阶段"。
3. **每一项都对应可验证的运行数据。** 数字可以从 git 日志、运行报告、账本记录里查到，不靠口述。

## 一句话版本

我做的事情可以概括成一句：**在跨境电商这个高度人工、高度重复的行业里，把「人肉搬数据」的环节一个个换成系统。**

财务从亚马逊后台下载 PDF 再手工录 Excel——换成自动解析。
报关员在五个国家的官网之间来回查税率——换成一个入口。
运营每天手写一篇文章发到六个平台——换成带质量门禁的自动管线。
客服在微信群里重复回答同样的问题——换成带知识边界的 AI 应答。

这些系统都不复杂，但每一个都要真的在业务里跑起来才算数。
