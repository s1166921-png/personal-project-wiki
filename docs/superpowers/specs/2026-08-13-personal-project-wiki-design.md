# 公开项目知识库与安全发布网站设计

日期：2026-08-13  
状态：待用户最终审阅  
目标域名：`wiki.meiouyuncang.com`

## 1. 目标

建立一套以 Obsidian 为唯一内容源的个人项目知识系统，并把经过脱敏审核的项目介绍、架构、成果和复盘自动发布为公开的面试作品集网站。

完整私人档案只保存在本地 Obsidian。公开网站只接收明确标记为 `public` 且通过敏感信息扫描的内容。

## 2. 已确认需求

- Obsidian 仓库保存在用户本地工作区，绝对路径不进入公开文档。
- 网站使用 `wiki.meiouyuncang.com`。
- 本地 Obsidian 保存完整项目档案；公开网站保存适合面试展示的脱敏视图。
- 公开内容包含目标、进度、公开决策、复盘、文档与成果，但不包含本地路径和内部资料。
- 网站允许所有人访问，不设置统一密码。
- Obsidian 保存内容后自动发布，目标延迟为 5–15 秒。
- 只同步专用的“个人项目库”目录，不同步整个本地仓库。
- 网站风格采用 Refero Monad 设计方向。
- GitHub 仓库与网站均公开，但严格排除安全信息和私人资料。

## 4. 项目档案模型

每个项目使用一致的 YAML 属性，网站和自动化脚本以这些字段生成导航、筛选和状态页面。

```yaml
---
title: 项目名称
type: project
status: active
area: AI与智能体
visibility: private
draft: false
created: 2026-08-13
updated: 2026-08-13
local_path: "本地私有字段，不进入公开输出"
priority: P1
tags: []
---
```

字段约束：

- `status`：`active`、`waiting`、`completed`、`archived`。
- `visibility`：`private` 或 `public`；只有明确设置为 `public` 的页面才可发布。
- `draft: true`：不发布到网站。
- `local_path`：仅供本地 Obsidian 使用；任何公开构建都自动移除。

每个项目正文固定包含：

1. 项目定位与背景
2. 目标与成功标准
3. 当前状态
4. 本周行动与下一步
5. 里程碑和进度记录
6. 关键决策
7. 文档与成果
8. 风险、阻塞和待确认事项
9. 复盘与经验
10. 本地路径和关联项目

大型工作区（例如 `project-codex`、`new`、`finance audit`）建立一级总卡，并为有独立目标或交付物的子目录建立子项目卡。

## 6. 网站体验

### 6.1 页面结构

- 顶部：品牌、主导航、全文搜索、私人登录状态。
- 首页首屏：知识库定位、项目规模、本周行动和同步状态。
- 左侧导航：全部项目、按状态、按领域、收集箱、决策、复盘和归档。
- 主内容：项目概览、项目卡片或 Markdown 正文。
- 文章页右侧：当前页目录、关联项目、最近更新。
- 移动端：折叠左右导航，保留搜索和正文阅读。

### 6.2 Monad 视觉系统

- 页面底色：Parchment `#f6f3f1`，不使用纯白作为主背景。
- 主文字：Off-Black `#242424`。
- 次级文字：Graphite `#4e4d4d`、Smoke `#797776`。
- 边框：Ash `#cecac8`，统一 1px。
- 唯一功能强调色：Lake Blue `#2b59d1`。
- 特色卡片：Periwinkle Mist `#cfdaf5`。
- 装饰渐变：Coral、Sky、Mint、Gold，仅作为柔和光晕，不作为功能状态色。
- 中文标题：宋体/思源宋体/Georgia 回退，字重 400。
- 正文和界面：等宽字体优先，中文回退到可读的系统字体。
- 卡片圆角 40px；按钮和标签为完整药丸形。
- 卡片依靠细边框和底色区分，不使用明显投影。

当前确认原型为 `website-concept.html`。

## 7. 技术架构

网站采用 Markdown 驱动的静态文档架构。实现计划优先选用 VuePress 2，因为其内容模型、侧边栏、页面目录和 Markdown 扩展与参考的 JavaGuide 网站相近，同时方便定制 Monad 主题。

主要组件：

1. Obsidian 内容目录：唯一人工编辑源。
2. 本地内容监听器：监听新增、修改和删除事件，并做防抖。
3. 发布过滤器：只允许专用目录、允许的附件类型和合法 Frontmatter。
4. 安全发布：只传输通过校验的公开构建产物，不传输私人原始档案。
5. 服务器构建器：生成静态 HTML、搜索索引、导航和站点地图。
6. Web 入口：提供 HTTPS、缓存和安全响应头。
7. 发布回滚：保留上一个成功版本，构建失败时继续提供旧站点。

## 8. 自动发布流程

```text
Obsidian 保存
  → 本地监听器防抖
  → 校验 Frontmatter 和内部链接
  → 排除草稿、敏感文件及非允许附件
  → 加密同步至服务器暂存目录
  → 服务器构建新版本
  → 构建与链接检查通过
  → 原子切换站点版本
  → 记录发布时间和结果
```

若校验、同步或构建失败：

- 线上继续保留最近一次成功版本。
- 本地写入可读错误日志。
- 不上传 `.env`、密钥、Git 元数据、源码目录、缓存、`node_modules` 或整个项目目录。
- 文件连续保存时合并为一次发布，避免频繁构建。

## 9. 公开访问与安全

- DNS 新建 `wiki.meiouyuncang.com` 记录；具体服务器地址只存放在本地部署配置中。
- 使用 HTTPS，证书自动续期。
- 网站公开访问，无登录或统一账号密码。
- 允许搜索引擎收录经过审核的公开页面。
- 发布前扫描口令、令牌、密钥、IP 地址、客户信息、本地绝对路径和常见敏感字段。
- 服务器只开放必要端口，发布账号仅能写入指定站点目录。
- 每日备份内容和最近成功构建，设定保留周期。
- 服务器凭据只在部署时读取和使用，不在对话、日志或生成文件中复述。

## 10. 私人资料隔离机制

- 本地 Obsidian 可以保存全部 `visibility: private/public` 内容。
- 公开站只构建 `visibility: public` 且 `draft: false` 的内容。
- 公开构建自动移除 `local_path`、内部决策、私人附件和其他受限字段。
- 发布前生成公开内容预览和敏感信息检查报告。

这保证私人档案与公开作品集可以共用内容源，但私人原文永远不会进入公开仓库或服务器发布目录。

## 11. 验收标准

### Obsidian

- `个人项目库` 目录结构完整，旧资料不被覆盖。
- 所有已发现一级项目均有项目卡，主要子项目有独立档案。
- 项目卡包含规定章节和可验证信息。
- 新项目可以通过模板快速录入。

### 网站

- `wiki.meiouyuncang.com` 通过 HTTPS 访问。
- 所有人均可使用导航、全文搜索、文章目录和项目筛选。
- 桌面端和移动端均可正常阅读。
- 视觉实现符合已确认的 Monad 原型。

### 自动发布

- 修改非草稿 Markdown 后，在正常网络条件下 5–15 秒内完成更新。
- `draft: true` 内容不会上线。
- 敏感和非允许文件不会传输。
- 构建失败时线上旧版本保持可用。
- 有清晰发布日志和可执行回滚步骤。

## 12. 实施边界

本阶段包括：内容库搭建、项目盘点、公开网站开发、安全过滤、自动发布、DNS 和服务器部署。

本阶段不包括：多人独立账号、邮箱验证码、在线编辑、评论系统、公开 SEO 运营或付费功能。这些能力可在私人版稳定后单独规划。
